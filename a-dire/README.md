# Textes à lire à voix haute

Déposez ici les fichiers `.txt` à faire lire par le Jarvis local
(voir `docs/etape-2-voix.md`).

Par exemple, Carson peut y déposer un résumé via le pont GitHub, puis :
`python scripts/lire_voix.py --fichier a-dire/resume.txt`

Les fichiers déposés ici sont versionnés dans le dépôt : ne jamais y mettre
de contenu sensible (mot de passe, code, information privée).
